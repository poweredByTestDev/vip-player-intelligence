
# VIP Player Intelligence

**AI-платформа для анализа переписок VIP-менеджеров**

VIP Player Intelligence — функциональный MVP для автоматизированного анализа коммуникаций VIP-менеджеров с игроками онлайн-казино.

Система помогает контролировать качество обслуживания, выявлять потенциальные риски, формировать рекомендации и отслеживать выполнение задач.

**Тип проекта:** MVP / тестовое задание  
**Технологии:** Next.js, React, JavaScript, Tailwind CSS, OpenAI API, Zod  
**Данные:** вымышленные, демонстрационные

---

## 1. О проекте

VIP-менеджеры ежедневно взаимодействуют с игроками через Telegram, WhatsApp и электронную почту.

Они помогают с депозитами и выводами средств, решают технические вопросы, сопровождают VIP-клиентов и поддерживают коммуникацию.

При работе с большой клиентской базой руководителю сложно регулярно оценивать качество всех переписок, своевременно выявлять проблемы и контролировать дальнейшие действия сотрудников.

VIP Player Intelligence решает эту задачу с помощью AI-анализа коммуникаций.

MVP объединяет три основных направления:

1. Анализ качества обслуживания.
2. Обнаружение и мониторинг рисков.
3. Управление задачами VIP-команды.

## 2. Демонстрационные данные

Для тестирования используются вымышленные данные:

- 40 переписок.
- 50 профилей игроков.
- 5 VIP-менеджеров.

Приложение не подключено к реальным игровым аккаунтам, Telegram, WhatsApp или CRM.

## 3. Основной функционал

### 3.1. Team Lead Dashboard

Интерфейс руководителя VIP-отдела.

Реализованы:

- Общая статистика команды.
- Мониторинг переписок.
- Показатели работы VIP-менеджеров.
- Поиск и фильтрация диалогов.
- Просмотр отдельных переписок.
- AI-анализ диалогов.
- Массовый анализ выбранных переписок.
- Отображение Quality Score.
- Мониторинг рисков.
- Контроль задач через Task Monitoring.

### 3.2. AI Conversation Analysis

Для анализа переписок используется OpenAI API.

AI формирует структурированный JSON-результат.

Основные параметры:

**Topic** — основная тема обращения.

**Sentiment** — эмоциональная окраска коммуникации:

- Positive
- Neutral
- Negative
- Mixed

**Resolution Status** — статус решения обращения:

- Resolved
- Unresolved
- Unknown
- No Request

**Quality Score** — демонстрационная оценка качества обслуживания от 0 до 100.

**Risk Level** — уровень потенциального риска:

- None
- Low
- Medium
- High
- Critical

**Summary** — краткое содержание переписки.

**Findings** — обнаруженные проблемы с подтверждающими цитатами.

**Next Actions** — рекомендации по дальнейшим действиям.

Интервалы ответов менеджера рассчитываются программно на JavaScript с использованием временных меток сообщений.

### 3.3. Quality Score

В MVP используется предварительная система оценки.

| Критерий | Максимальный балл |
|---|---:|
| Решение проблемы (Resolution) | 30 |
| Коммуникация (Communication) | 20 |
| Скорость ответа (Response Time) | 15 |
| Персонализация (Personalization) | 10 |
| Выполнение обещаний (Promises) | 10 |
| Безопасность (Safety) | 15 |
| **Итого** | **100** |

Если критерий неприменим или данных недостаточно, он исключается из расчёта.

Итоговая оценка нормализуется по применимым критериям.

**Важно:** эта методика носит демонстрационный характер.

В техническом задании не были указаны конкретные KPI, SLA, веса критериев и правила выставления оценок.

При внедрении в рабочие процессы методика должна быть согласована с требованиями компании.

### 3.4. Risk Detection

Система выявляет потенциальные проблемы обслуживания и Responsible Gaming.

В частности:

- Запросы на самоисключение.
- Просьбы заблокировать игровой аккаунт.
- Сообщения о финансовом вреде от игры.
- Признаки проблемного игрового поведения.
- Попытки удержания игрока при запросе на самоисключение.
- Нерешённые обращения.

Для некоторых критических сценариев AI-анализ дополняется проверками на JavaScript.

При обнаружении критического нарушения менеджера итоговый Quality Score ограничивается 20 баллами.

Обнаружение рисков не является исчерпывающим.

Критические случаи требуют проверки человеком.

Приложение не выполняет автоматическую блокировку аккаунтов.

### 3.5. VIP Manager Workspace

Рабочий интерфейс VIP-менеджера.

Возможности:

- Выбор менеджера в демонстрационном режиме.
- Просмотр закреплённых игроков.
- Приоритизация обращений.
- Просмотр истории переписки.
- Просмотр AI-анализа.
- Получение рекомендаций.
- Управление задачами.

Индивидуальная оценка Quality Score менеджеру не показывается.

Выбор менеджера не является полноценной авторизацией.

### 3.6. Task Management

Рекомендации AI используются для формирования задач.

Поддерживаемые статусы:

- To Do — новая задача.
- In Progress — задача в работе.
- Done — задача выполнена.

Менеджеры могут:

- Изменять статусы.
- Добавлять комментарии.
- Сохранять результаты работы.

Руководитель отслеживает задачи через Task Monitoring.

Для критических задач предусмотрены дополнительные требования к комментариям.

Статус Done не подтверждает автоматически выполнение действий во внешних системах.

## 4. Демонстрационные сценарии

В проекте используются три основных контрольных сценария.

### D001 — Проблема с депозитом

Игрок сообщает о повторных неудачных попытках пополнения счёта.

Менеджер предлагает бонус вместо конкретной технической помощи.

Система выявляет недостатки обслуживания и отсутствие подтверждённого решения.

### D007 — Задержка выплаты

Игрок обращается из-за задержки вывода средств.

VIP-менеджер помогает с документами и взаимодействием с платёжным отделом.

Сценарий демонстрирует пример качественного обслуживания.

### D010 — Запрос на самоисключение

Игрок сообщает о проигрыше зарплаты и просит заблокировать аккаунт.

Менеджер пытается удержать игрока с помощью кешбэка.

Сценарий демонстрирует выявление критического нарушения Responsible Gaming.

## 6. Установка и запуск

### Требования

- Node.js.
- npm.
- API-ключ OpenAI.
- Интернет для выполнения AI-запросов.

### Шаг 1. Получение проекта

Скачайте репозиторий в виде ZIP-архива или клонируйте его.

Распакуйте файлы и откройте корневую папку проекта в терминале.

### Шаг 2. Установка зависимостей

```bash
npm install
```

### Шаг 3. Настройка OpenAI API

В корневой папке проекта создайте файл:

`.env.local`

Добавьте строку:

```env
OPENAI_API_KEY=your_openai_api_key_here
```

В проекте предусмотрен файл `.env.example` с примером настройки.

Не публикуйте настоящий API-ключ.

### Шаг 4. Запуск приложения

```bash
npm run dev
```

После запуска откройте:

http://localhost:3000

### Шаг 5. Production-сборка

Для проверки сборки:

```bash
npm run build
```

Для запуска собранного приложения:

```bash
npm run start
```

## 9. Контроль качества

В проекте реализован QA-скрипт.

Запуск:

```bash
node scripts/qa-check.mjs
```

Скрипт проверяет:

- Структуру JSON.
- Допустимые диапазоны оценок.
- Корректность расчётов.
- Наличие подтверждающих цитат.
- Структуру рекомендаций.
- Согласованность задач и анализов.

Автоматические структурные проверки не гарантируют смысловую точность всех выводов AI.

Дополнительно выполнялась ручная проверка контрольных сценариев.

## 12. Итог

VIP Player Intelligence демонстрирует полный рабочий процесс:

**Переписка → AI-анализ → Выявленные проблемы → Рекомендации → Задачи → Контроль выполнения**

Проект представляет собой функциональный MVP, а не готовую production-систему.

Основная цель — показать возможности интеграции AI в процессы VIP-отдела и потенциал дальнейшего развития инструмента под бизнес-требования компании.
